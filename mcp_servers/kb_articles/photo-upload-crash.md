# App Crashes When Uploading a Photo

This is a known issue on some devices when uploading photos larger than 10MB.

Workarounds:

1.Resize the photo to under 10MB before uploading.
2.Update the app to the latest version — this was partially fixed in recent updates.
3.Try uploading over WiFi instead of mobile data, as slow connections can trigger the same crash.

If the crash continues after trying these steps, it's likely a device-specific bug and should be escalated to engineering with the device model and app version.
